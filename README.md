# Спільний перегляд

## Запуск локально
    npm install
    npm start
Відкрийте http://localhost:3000

## Деплой на Render (безкоштовно)
1. Створіть репозиторій на GitHub і завантажте туди ці файли.
2. На render.com: New -> Web Service -> підключіть репозиторій.
3. Runtime: Node. Build Command: `npm install`. Start Command: `npm start`. Plan: Free.
4. Після деплою скопіюйте адресу виду https://назва.onrender.com і скиньте друзям.
Примітка: на безкоштовному плані сервіс "засинає" після ~15 хв без активності, перший вхід тоді триває до хвилини.
